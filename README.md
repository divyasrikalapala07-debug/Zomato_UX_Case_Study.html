# 🍽️ Zomato UX Case Study

## 📌 Project Overview

This project is a UX case study of the Zomato food delivery and
restaurant discovery platform.

The study analyzes the user journey, strengths, weaknesses and
possible UX improvements.

---

## 🎯 Objectives

- Analyze the Zomato user journey
- Identify UX strengths
- Identify UX weaknesses
- Suggest 3 UX improvements
- Create sample UI mockups

---

## 👤 Target Users

- Students
- Working professionals
- Families
- Online food ordering users
- Restaurant discovery users

---

## 🔄 User Journey

1. Open the application
2. Search for food or restaurant
3. Select a restaurant
4. Place an order
5. Track delivery

---

## 💪 UX Strengths

### 1. Easy Food Discovery
Users can search for different foods, cuisines and restaurants.

### 2. Restaurant Information
Users can view menus, ratings and reviews.

### 3. Order Tracking
Users can track their food delivery.

---

## ⚠️ UX Weaknesses

### 1. Information Overload
A large amount of information can make the interface feel crowded.

### 2. Difficult Comparison
Users may need to open multiple restaurant pages to compare options.

### 3. Checkout Complexity
The checkout experience can be simplified.

---

## 💡 Proposed Improvements

### 1. Smart Restaurant Comparison
Compare restaurants based on rating, price and delivery time.

### 2. Simplified Checkout
Show items, delivery fee and total amount clearly.

### 3. Personalized Search
Provide recommendations based on frequently ordered food.
